# CSS Modules

Modular Light-Mode-First design system imported in order by `../style.css`:

- `00-tokens.css` — Warm Ivory (`#FAF9F6`), Soft Neutral (`#F0EFEA`), Deep Ink (`#20212A`), Electric Blue (`#4169F5`), Coral Orange (`#FF735C`), Lemon Yellow (`#F8D95B`), Lavender (`#B8A5F5`), typography scale, and dark-theme toggle tokens.
- `01-base-layout.css` — Base reset, skip link, `:focus-visible` outlines, forced-colors support, architectural grid backdrop, section framing, and buttons.
- `02-navbar-footer.css` — Fixed editorial navbar, mobile drawer, and footer.
- `03-hero.css` — Hero editorial typography, floating geometric composition, tech-stack visualization, and interactive engineering workbench.
- `04-cinematic-story.css` — Scroll-scrubbed scrollytelling stage.
- `05-about-experience.css` — Developer origin story scrubber, status terminal, quote box, and experience cards.
- `06-skills.css` — Domain-colored bento toolkit grid.
- `07-projects.css` — Project filter bar, search input, and editorial project cards.
- `08-journey-cms.css` — Achievements summary cards, colourful dynamic timeline, and Journey CMS Admin Studio.
- `09-studio-contact.css` — Home preview cards, Curious Minds Studio anchor panel, direct contact channels, and accessible brief form.
- `10-modals-feedback.css` — Project, Story, and Terminal modals, toast notifications, BackToTop, and WhatsApp action.
- `11-motion-responsive.css` — View-timeline & IntersectionObserver reveals, split-heading motion, `prefers-reduced-motion`, and responsive breakpoints (`320px` to `1920px+`).
