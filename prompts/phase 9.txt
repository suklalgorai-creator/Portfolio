# PHASE 9 — ADVANCED MOTION, ANIMATION & INTERACTIVE EXPERIENCE

## ROLE

Act as a world-class Creative Developer, Motion Design Director, GSAP Specialist, Three.js Developer and Interactive Experience Engineer.

Your mission is to transform my existing portfolio into a premium, cinematic and highly interactive web experience.

The website should feel alive, immersive, fluid and professionally art-directed.

This is a FRONTEND MOTION AND INTERACTION PHASE ONLY.

Do not start backend development, database work or security implementation.

---

# 1. FIRST — AUDIT EXISTING ANIMATIONS

Before implementation:

- Inspect all existing GSAP animations.
- Inspect ScrollTrigger implementations.
- Inspect existing CSS animations and transitions.
- Identify duplicate, conflicting or unnecessary animations.
- Identify animations that cause layout shifts or jank.
- Check animation cleanup and React component lifecycle.
- Check existing 3D elements and interaction logic.

Do not replace working animations unnecessarily.

Create a motion implementation plan before modifying the code.

# 2. ESTABLISH A GLOBAL MOTION SYSTEM

Create a consistent animation language across the website.

Define reusable motion tokens:

- Fast interaction: 150–250ms.
- Standard transition: 300–500ms.
- Expressive transition: 600–900ms.
- Cinematic transition: 1000–1600ms.
- Subtle floating loops: 4–8 seconds.

These are starting guidelines, not mandatory timings for every animation.

Use:
- Smooth easing curves.
- Controlled stagger animations.
- Natural spring-like movement where appropriate.
- Subtle opacity and transform combinations.
- Scroll-based progression.
- Layered depth and parallax.

Create reusable animation utilities and avoid writing isolated animation logic for every component.

# 3. HERO SECTION — CINEMATIC EXPERIENCE

Make the hero section the strongest motion experience.

Implement:

### Portrait animation
- Smooth entrance animation.
- Subtle floating movement.
- Controlled parallax based on pointer movement.
- Independent layer animation.
- Natural depth and perspective.

### Holographic sphere
- Slow rotation.
- Subtle light movement.
- Interactive response to pointer movement.
- Controlled glow and reflection changes.

### Liquid glass ribbons
- Smooth flowing motion.
- Subtle deformation where technically practical.
- Layered depth.
- Independent movement.
- Avoid excessive visual noise.

### Orbital technology icons
- Multiple orbital layers.
- Different speeds and directions.
- Independent elliptical paths.
- Smooth rotation and floating movement.
- Hover elevation and technology labels.
- Subtle interaction feedback.

The orbit must look spatial and dimensional, not like a flat rotating carousel.

### Hero text
- Cinematic text reveal.
- Controlled line-by-line entrance.
- Subtle character or word animation where appropriate.
- Keep text readable throughout.

# 4. CINEMATIC SCROLL STORYTELLING

Implement:

- Section entrance reveals.

- Scroll-linked visual progression.
- Layered content transitions.
- Sticky storytelling where appropriate.
- Progress indicators for long sections.

For CinematicStorySection:

- Handle loading and seeking states.
- Provide a fallback if the video cannot load.
- Avoid forcing users to scroll through unnecessarily long sections.
- Ensure mobile performance.

Do not make every section sticky or scroll-scrubbed.

Use cinematic effects selectively.

# 13. PERFORMANCE REQUIREMENTS

Motion must never compromise usability.

- Use transform and opacity wherever possible.
- Avoid unnecessary layout-triggering animations.
- Avoid excessive simultaneous ScrollTriggers.
- Use will-change selectively.
- Clean up GSAP timelines and ScrollTriggers on component unmount.
- Prevent memory leaks.
- Avoid unnecessary React re-renders.
- Lazy-load heavy 3D scenes.
- Use lightweight mobile alternatives where needed.
- Avoid unnecessary video decoding.
- Ensure animations do not block interaction.

Respect prefers-reduced-motion.

When reduced motion is enabled:
- Disable unnecessary parallax.
- Disable decorative continuous animations.
- Replace large transitions with simple fades.
- Preserve all functionality.

# 14. RESPONSIVE MOTION

Desktop:
- Full cinematic motion.
- Pointer-based effects.
- Richer depth and parallax.

Tablet:
- Reduced complexity.
- Touch-friendly interactions.
- Controlled animation density.

Mobile:
- Lightweight transitions.
- No mouse-dependent features.
- Reduced particle and 3D complexity.
- No scroll-jacking.
- No unnecessary sticky effects.
- Smooth scrolling and readable content.
