# Suklal Gorai — Portfolio Website

Personal developer portfolio & CodeCraft Digital agency showcase.

## 🚀 Built With
- **HTML5, CSS3, JavaScript (ES6+)** — Zero framework bloat, instant loading
- **Theme** — Cyber-Emerald Glassmorphism & Attendance Tracker Dark/Daylight theme
- **Design System** — Outfit + JetBrains Mono typography
- **Interactive Features** — Developer Terminal, Constellation Canvas, APK Download Engine, Project Modals

## 📁 Structure
```
portfolio/
├── index.html          # Main entrypoint
├── css/
│   └── style.css       # Full responsive styles & theme tokens
├── js/
│   └── main.js         # Interactive scripts, terminal, modals
└── assets/
    ├── images/         # Project previews & avatar
    └── apk/            # Android application downloads
```

## 📱 Mobile & Desktop
Fully optimized for all devices with touch controls, swipeable sections, and responsive layout.
